# Student Planner

A Notion-inspired student workspace with predefined academic templates.

## Features

- Student dashboard
- Notion-style pages
- Predefined templates
- Subjects
- Tasks
- Calendar
- Local browser persistence for the MVP
- Responsive UI

## Run

```bash
npm run install-all
npm run dev
```

The frontend runs with Vite. The backend scaffold can be started separately with:

```bash
npm run server
```

## Project structure

- `client/` - React frontend
- `server/` - Express backend scaffold
